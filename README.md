## 2. 핵심 기능 및 특징

1. **Warm Luxury & Minimalism 디자인**:
   - 오프화이트, 딥차콜, 샴페인 골드 기반의 럭셔리 매거진 룩북 스타일
   - 하이엔드 세리프 서체와 정제된 고딕 서체의 조화
2. **실물 브랜드 에셋 적극 반영**:
   - 옷 안쪽 부착용 **블랙 직조 라벨 (`HWANG GEUM since 1990`)**
   - 공식 국/영문 로고 (`황금모피 HWANG GEUM`)
   - 장인의 작업실 실물 컷 (스킨 판장 및 정밀 V자 절개, 특수 재단 툴, 안감 손바느질 마감, 쇼룸 랙 컬렉션)
3. **실제 스마트스토어 40개 상품 룩북 & 퀵뷰 모달**:
   - 카테고리별 필터: `ALL`, `Jacket & Coat`, `Vest & Hood`, `Muffler & Scarf`, `Acc & Hat`
   - 상품 카드 클릭 시 매거진 퀵뷰 모달(멀티 썸네일 갤러리, 스펙, 네이버페이 구매 바로가기)
4. **타협 없는 7단계 장인 제작 공정 (CRAFT)**:
   - 선별 → 스킨 판장 → 1차 성형 → 특수 미싱 → 2차 조립 → 시침/완성 → 전수 검수 인터랙티브 탭
   - 3대 기술 약속(털 빠짐 방지, 재봉선 은폐 기술, 균일한 장모/단모 비율)
5. **동대문 쇼룸 피팅 & 맞춤 상담 예약 시스템**:
   - 사전 예약제 폼 (성함, 연락처, 방문 일시, 관심 상품, 맞춤 요청 메모)
   - 네이버 지도 및 카카오맵 길찾기 바로가기

## 3. 실행 방법 (로컬 프리뷰)

별도의 복잡한 설치 없이 Python 또는 Node.js 기본 서버로 즉시 실행할 수 있습니다.

### 방법 1) Python 내장 서버 (추천)
```bash
# hwanggum 폴더에서 실행
python -m http.server 3000
```
브라우저에서 `http://localhost:3000` 접속

### 방법 2) Node.js npx serve
```bash
npx serve .
```
